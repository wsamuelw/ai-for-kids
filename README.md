# Bolt's AI Adventure 🤖

A fun, interactive online course teaching kids aged 5-7 about Artificial Intelligence.

## What's Inside

- **Bolt the Robot** — a friendly mascot guide who walks kids through each section
- **6 Learning Steps** — What is AI, What Can AI Do, AI Helps Us, Cool Tools, The Future, Staying Safe
- **Mini-Checks** — quick quiz after each section with immediate feedback
- **Gamification** — earn badges as you complete each step
- **Final Quiz** — 3-question challenge with score tracking
- **Printable Certificate** — personalised with the child's name and today's date
- **Parent Tips** — co-learning prompts in every section

## Quick Start

Open `index.html` in any browser. No build step, no dependencies.

```bash
open index.html
```

## Deploy to GitHub Pages

1. Create a new GitHub repo
2. Push this folder to the repo
3. Go to Settings > Pages
4. Set source to "Deploy from a branch" > main
5. Your course will be live at `https://yourusername.github.io/repo-name/`

## Tech Stack

- Single HTML file
- Inline CSS (no external stylesheets)
- Vanilla JavaScript (no frameworks)
- Google Fonts (Baloo 2 + Nunito)
- Zero dependencies

## Course Structure

| Step | Section | What Kids Learn |
|------|---------|-----------------|
| 1 | What is AI? | AI learns from examples, just like you |
| 2 | What Can AI Do? | Draw, chat, make music, create videos |
| 3 | AI Helps Us | Voice assistants, videos, games, learning apps |
| 4 | Cool Tools | ChatGPT, Claude, Gemini, ElevenLabs |
| 5 | The Future | Robot friends, smart toys, dream machines |
| 6 | Staying Safe | AI makes mistakes, ask a grown-up, keep secrets safe |

## Features

- Responsive design (works on phones, tablets, desktop)
